# 데이터 정의

## 수집 시작과 종료

수집 동의 시점부터 기록합니다. 첫 동의 이전의 프롤로그 시간은 포함하지 않습니다. 다음 방문부터는 이전 동의 여부를 기억합니다. 수집 거절/중단은 이후 기록과 전송 대기를 제거하며, 이미 서버에 보낸 기록을 소급 삭제하지 않습니다.

15초마다 누적 스냅샷을 저장하며, 장 진입/시작, 성공, 실패, 탭 숨김/복귀, 페이지 이탈에도 기록합니다. `seq`가 가장 큰 스냅샷이 해당 시도의 최신 상태입니다. 이벤트 ID를 동일하게 재전송하므로 동일 이벤트의 재전송이 실패 횟수를 늘리지 않습니다.

## 시도별 CSV

| 필드 | 의미 |
|---|---|
| `sessionId` | 페이지 로드 후 수집을 시작할 때 만든 무작위 세션 ID |
| `attemptId` | 장에 진입하거나 재시작할 때 만든 시도 ID |
| `chapter` | 장 번호 1~15 |
| `attempt` | 같은 세션에서 해당 장의 몇 번째 시도인지 |
| `debug` | 장 바로가기 해시로 들어온 테스트 플레이 |
| `startedAt` | 시도 측정 시작 시각, UTC ISO 8601 |
| `observedAt` | 스냅샷 발생 시각, 브라우저 시계 기준 UTC |
| `receivedAt` | 서버 수신 시각, 재전송 시 마지막 수신 시각 |
| `wallMs` | 장 진입부터 마지막 기록까지 실제 경과 시간. 타이틀/결과/숨겨진 탭 포함 |
| `activeMs` | 그중 탭이 보이는 시간. 조작 여부와 무관 |
| `playMs` | 게임이 시작되었고 결과가 나오기 전, 탭이 보이는 시간 |
| `clearWallMs` | 해당 시도의 진입부터 클리어 사건까지 경과 시간. 미클리어는 빈 값 |
| `clearActiveMs` | 위 기간의 탭이 보이는 시간 |
| `failures` | 해당 시도 실패 시 1, 그 외 0. 같은 사망 처리의 중복 호출은 무시 |
| `reason` | fall / cart_abandoned / car_collision / escape_failure / dog_attack / starvation / ice_melt |
| `errors` | 수집 중 오류/미처리 Promise 오류 발생 횟수. 페이지당 최대 20회 기록, 원문 미수집 |
| `status` | ready / playing / failed / cleared / abandoned |
| `event`, `seq` | 마지막 이벤트 유형과 시도 내 스냅샷 순번 |

`ready`는 장 타이틀 화면, `playing`은 진행 중입니다. `abandoned`는 클리어/실패 전에 다른 장이나 새 시도로 전환한 상태입니다. 탭을 닫거나 강제 종료한 세션은 `playing`/`ready`가 마지막 상태일 수 있으므로 '현재 접속 중'이라는 의미가 아닙니다. 성공/실패 후 결과 화면 체류는 wallMs/activeMs에 계속 더해지지만 clear 시간/playMs는 늘지 않습니다.

## 세션·장별 CSV

동일 세션·장에 속한 시도를 묶습니다. 실패한 시도와 성공한 시도를 모두 포함합니다.

- `attempts`: 관측된 시도 수. 재시작 횟수는 `attempts - 1`입니다.
- `failures`: 시도별 실패의 합계. 그냥 다시 시작한 행동은 실패에 포함하지 않습니다.
- `clears`: 클리어한 시도 수.
- `wallMs`, `activeMs`, `playMs`, `errors`: 각 시도의 누적 값 합계.
- `firstClearWallMs`: 해당 장 최초 진입부터 첫 성공까지 실제 경과 시간. 실패와 재시도·대기 시간을 포함합니다.
- `firstClearActiveMs`: 첫 성공까지 보이는 탭에서 보낸 누적 시간.
- `firstClearAt`: 첫 성공 시각. 실패하거나 중도 종료한 경우 빈 값.

관리자 화면의 '세션'은 사람 수가 아닙니다. 평균 클리어 시간은 성공 세션만 포함합니다. 중도 포기 데이터와 함께 해석해야 합니다.

## 게임 연결 기준

- 1장 `showFinale`, 일반 장 `finale2`, 동굴에서 터널로 이어지는 `explode4`, 매립지의 이야기상 충돌 `crash9`, 최종 `theEnd15`를 성공으로 계측합니다.
- 맵 밖 추락, 수레 포기, 고속도로 차량 충돌, 계류장 탈출 실패, 들개 접근 공격, 굶주림, 얼음섬 사망을 실패로 계측합니다.
- 단순히 장 번호가 바뀌었다고 이전 장을 클리어한 것으로 추정하지 않습니다.
- 얼음섬 실패는 기존 사망 화면 함수에서 기록하므로 사망 연출 약 2.2초가 playMs에 포함될 수 있습니다.

## 정확도와 제한

- 관리자 날짜 범위는 한국 시간으로 입력받아 UTC 시간별 저장 키로 조회합니다. CSV의 원본 시각은 UTC이고 시간 수치는 ms입니다.
- 날짜 필터는 **이벤트 발생 시각** 기준입니다. 며칠에 걸친 세션은 시작일~종료일을 함께 선택해야 첫 진입/실패 횟수가 완전합니다. 선택 기간 이전 기록은 조회/집계하지 않습니다.
- 브라우저를 강제 종료하거나 오랫동안 오프라인이면 마지막 기록이 유실될 수 있습니다. 15초 heartbeat와 페이지 종료 전 keepalive 전송은 보완 수단이며 전달 보장은 아닙니다.
- 오프라인 이벤트를 localStorage에 최대 1,000개 보관하고 다음 동의 방문 시 재전송합니다. 초과 시 오래된 이벤트부터 제거합니다. 브라우저 저장소 차단/삭제, 여러 탭의 동시 오프라인 사용에서는 복구가 제한됩니다.
- 각 기록은 클라이언트 시계를 사용하므로 시스템 시각 변경과 조작의 영향을 받습니다. 서버 수신 시각은 별도로 저장합니다.
- 숨겨진 탭 시간은 activeMs에서 제외하지만, 화면만 켜 놓고 자리를 비운 시간은 포함됩니다. '실제 조작 시간'으로 해석하면 안 됩니다.
